# Navigation et simulation — sources disponibles

`Sources_frontend/` regroupe le composant React de simulation, son style, la scène et le scénario animés. La maquette autonome, les mondes SDF et le script Gazebo sont dans `Maquette_AGV_Bancaire_v0_2/Maquette_AGV_Bancaire_v0_2/`.

Ces éléments représentent un parcours conceptuel avec des états simulés. Ils ne constituent ni un planificateur Nav2, ni une navigation autonome validée, ni un essai du robot. Gazebo doit être installé pour exécuter les mondes ; le contrôle de l’AGV réel n’est pas inclus.
