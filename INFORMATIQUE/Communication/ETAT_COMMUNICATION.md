# Communication informatique — état actuel

Le prototype React/Vite fonctionne localement avec des missions et états simulés. Les sources n’établissent aucun protocole réseau, API, backend, interface ROS 2 ou liaison avec l’AGV bancaire.

Le fichier `INTERFACES_A_DEFINIR.csv` est un registre vierge à renseigner après confirmation des interfaces disponibles sur l’équipement réel. Il ne décrit aucune commande opérationnelle.
